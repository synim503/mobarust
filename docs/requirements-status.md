# Статус требований MobaRust

Требования взяты из исследования [«Юзабилити SSH клиентов»](../reports/Юзабилити%20SSH%20клиентов.md):
анализ Termius, MobaXterm, SecureCRT, Xshell, Tabby, WindTerm, PuTTY/KiTTY, Royal TS, Bitvise, Electerm, WezTerm и других.

Обозначения: ✅ сделано · ◐ частично (что именно не сделано — в комментарии) · ⬜ не сделано.
«Проверено» — сценарий прогнан интеграционным тестом против живого `sshd` (см. README, раздел «Тесты»)
или вручную в GUI.

## Must

| ID | Требование | Статус | Как сделано / что осталось |
|---|---|---|---|
| SEC-01 | Ключ хоста — жёсткий барьер, TOFU с SHA256, блокировка при подмене | ✅ проверено | Проверка в `check_server_key` до любой аутентификации; при подмене — красная панель без «продолжить», удаление записи — отдельное явное действие с копией `known_hosts.old`. Тест: при подмене ключа пароль не запрашивается |
| SEC-02 | Агенты: `SSH_AUTH_SOCK` → `\\.\pipe\openssh-ssh-agent` → Pageant, подсказка при выключенной службе | ✅ | Порядок реализован; на Linux проверено с `ssh-agent`. Windows-пути собраны и проверены компиляцией, на живой Windows не прогонялись |
| SEC-03 | Ключи OpenSSH, PEM, PPK; passphrase с кэшем; явная ошибка с путём | ◐ проверено | OpenSSH/PEM ✅, passphrase спрашивается один раз на цепочку. **PPK не читается** — распознаётся и показывается команда конвертации `puttygen` |
| SEC-04 | Пароли не хранятся открытым текстом | ◐ | Только по галочке «Запомнить», каждый секрет шифруется Windows DPAPI. Мастер-пароля нет; на Linux/macOS сохранение паролей отключено |
| SES-01 | Строка быстрого подключения, нечёткий поиск, ad hoc → сохранить | ✅ проверено | Ctrl+Shift+K / Ctrl+Shift+P. Ctrl+K и Alt+R не заняты намеренно — это kill-line и revert-line в bash (UX-01). Ad hoc-сессии сохраняются автоматически |
| SES-02 | Дерево с папками, поиском, тегами, наследованием от папки | ◐ | Папки, фильтр, теги, «открыть все», переименование и удаление папок, «Недавние». **Наследования настроек от папки нет** |
| SES-03 | Импорт `~/.ssh/config` с Include и ProxyJump, отчёт о пропущенном | ✅ проверено | Юнит-тест с Include, `Host *` и ProxyJump |
| SES-04 | ProxyJump и цепочки, у каждого шага свои учётные данные | ✅ проверено | `direct-tcpip` + `connect_stream`; jump-токен может ссылаться на сохранённую сессию по имени |
| TRM-01 | Вкладки и split-панели; цвет вкладки на профиль | ◐ | Вкладки, раскладки 1 / 2 колонки / 2 строки / 4 панели, цвет вкладки и рамки. **Произвольного вложенного split и цветовых схем на профиль нет** |
| TRM-02 | Локальные shell через ConPTY: cmd, PowerShell, WSL | ✅ | Автоопределение pwsh / powershell / cmd / дистрибутивов WSL; `wsl -l` вызывается с `CREATE_NO_WINDOW` |
| TRM-03 | Безопасная вставка | ✅ проверено | Ctrl+C копирует при выделении, иначе шлёт ^C. Многострочная вставка или больше 5 КБ — диалог с правкой и «одной строкой», если программа не включила bracketed paste. PuTTY-режимы — опции |
| TRM-04 | Поиск по истории (Ctrl+Shift+F), ограниченный scrollback | ✅ | По умолчанию **5000 строк**, а не 10 000: ячейка vt100 — 32 байта, 10 000 строк дают ~38 МБ на вкладку при 120 колонках. Настраивается |
| TRM-05 | xterm-256color, true color, CJK/эмодзи | ◐ | 256/truecolor, режим курсора приложения, отчёты мыши (htop, mc), широкие символы. vttest не прогонялся |
| SFTP-01 | SFTP-панель, отдельный канал, очередь с прогрессом, рекурсивно, drag-and-drop | ◐ проверено | Отдельный канал (ошибка SFTP не рвёт shell), прогресс, папки рекурсивно, перетаскивание из Проводника, удаление и переименование. Передачи идут последовательно, **докачки нет** |
| REL-01 | Keep-alive 15–30 с × 3, состояние «Отключено» видно | ✅ проверено | 15 с × 3 (настраивается); точка на вкладке, баннер, статус-бар |
| REL-02 | Переподключение одной клавишей с сохранением истории, автоповтор | ✅ проверено | R или Enter в отключённой вкладке, Ctrl+Shift+R; автоповтор 2→60 с только после обрыва (не после `exit`); пароль берётся из кэша сессии |
| BRD-01 | Рассылка ввода, индикатор, исключение панелей | ✅ проверено | Ctrl+Shift+B, красная рамка и 📢 на вкладках, «Исключить из рассылки» в меню вкладки |
| CFG-01 | Атомарная запись, резервные копии, миграции | ✅ | tmp + fsync + rename, 3 копии, версия схемы, битый файл откладывается, а не перезаписывается |
| CFG-02 | Портативный режим и %APPDATA%; настройки отдельной страницей | ✅ | Файл `portable` рядом с exe → данные в `data\` |
| CFG-03 | Никаких тихих автообновлений | ✅ | Автообновлений нет вообще |
| CFG-04 | Без аккаунта, без телеметрии, открытый код, подписанные релизы | ◐ | Всё, кроме подписи: сертификата нет (вариант — SignPath Foundation для open source) |
| UX-01 | Всё с клавиатуры, без конфликтов с shell, переназначаемо | ◐ | Все действия доступны с клавиатуры и через палитру, все горячие клавиши на Ctrl+Shift. **Переназначения пока нет** |
| WIN-01 | Без консольного окна, Per-Monitor DPI v2 | ◐ | `windows_subsystem = "windows"` ✅; DPI берёт на себя winit, на мониторах с разным DPI не проверялось |

## Нефункциональные

Числа измерены на Linux (Xvfb, программный рендеринг llvmpipe), а не на Windows. Это ориентир, а не замер под целевую ОС.
Значения — в README, раздел «Производительность».

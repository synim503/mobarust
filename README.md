# MobaRust

Кроссплатформенный терминальный / SSH-клиент в духе **MobaXterm**, написанный на Rust.
MVP-каркас: менеджер сессий, вкладки терминалов, локальный шелл и SSH — в одном окне.

> Статус: рабочий фундамент (MVP). Ядро архитектуры на месте, его легко расширять
> до полноценного клиента (SFTP, split-панели, MultiExec, туннели, X-сервер).

## Возможности сейчас

- **Менеджер сессий** слева: папки (создание, пустые тоже видны), поиск по дереву.
- **Авто-сохранение**: каждая добавленная SSH-сессия сразу пишется в конфиг ОС (JSON);
  при повторном подключении форма преднастроена (секреты не хранятся).
- **SSH-аутентификация**: пароль **или приватный ключ** (`load_secret_key`,
  rsa-sha2-512 для RSA), с passphrase.
- **Вкладки терминалов** с индикатором «жив / отключён».
- **Локальный шелл** через псевдотерминал (`portable-pty`): bash / zsh / pwsh / cmd.
- **SSH** на чистом Rust (`russh`): PTY + интерактивный shell, авто-ресайз.
- **Эмуляция терминала** через `vt100`: ANSI-цвета (16/256/truecolor), курсор,
  жирный, инверсия, полноценный ресайз под размер окна.
- **Быстрое подключение**: строка `user@host:port` + Enter.
- Тёмная тема, маршрутизация клавиатуры (Ctrl-комбинации, стрелки, F1–F4, PageUp/Down).
- **Без окна консоли** на Windows (release-сборка — `windows_subsystem = "windows"`).

## Оптимизация

- Рендер терминала кэширует разложенные строки (`Galley`) и перелэйаучивает их только
  при реальном изменении вывода (счётчик поколений) или размера/шрифта; в простое кадр
  лишь перерисовывает готовые галеи — без блокировки мьютекса. Подряд идущие ячейки
  группируются в текстовые и фоновые раны (меньше примитивов).
- Release-профиль: `opt-level=3`, `lto="fat"`, `codegen-units=1`, `strip=true`.

## Архитектура

```
src/
  main.rs            точка входа, окно eframe
  config.rs          модель сессий (SessionDef/SessionKind) + хранение JSON
  app.rs             UI: тулбар, дерево сессий, вкладки, статус-бар, диалог SSH
  terminal/
    mod.rs           TermSession (общая абстракция), палитра, ввод, рендер vt100→egui
    local.rs         локальный PTY-бэкенд (portable-pty)
    ssh.rs           SSH-бэкенд (russh на tokio-рантайме в отдельном потоке)
```

Каждая сессия держит `vt100::Parser` под мьютексом. Фоновый поток читает вывод
(PTY или SSH-канал) и кормит парсер, ставя флаг «перерисовать»; UI раз в кадр
рисует сетку ячеек и отправляет ввод пользователя обратно в канал.

## Сборка и запуск

Нужен Rust (edition 2024, проверено на 1.97) и графическое окружение.

```bash
cargo run --release
```

Без SSH (меньше зависимостей, не тянет russh/tokio):

```bash
cargo run --release --no-default-features
```

### Системные зависимости GUI (Linux)

Для `eframe`/`winit` на Linux нужны библиотеки X11/Wayland, например (Debian/Ubuntu):

```bash
sudo apt install libx11-dev libxcb1-dev libxkbcommon-dev libwayland-dev
```

> Приложение графическое — в headless-окружении (CI, облачный контейнер без дисплея)
> оно собирается, но не запускается без X11/Wayland.

## Горячие клавиши

| Клавиши             | Действие                          |
|---------------------|-----------------------------------|
| `Enter` в omnibox   | подключиться по `user@host:port`  |
| `Ctrl`+`C/D/Z/…`    | управляющие байты в терминал      |
| стрелки, `Home/End` | навигация в терминале             |
| `F1`–`F4`           | функциональные клавиши            |

## Безопасность

MVP принимает **любой** ключ хоста (`check_server_key → true`) и не проверяет
`known_hosts` — перед реальным использованием это нужно исправить. Пароли в конфиге
не сохраняются.
